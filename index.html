Quick answers

The things people ask before their first bounty.

Do I need to be a programmer to enter?

No. Your AI coding agent writes the software — you pick the bounty, steer the agent and submit the entry. Many entrants have never shipped code by hand.

How do I know the prize is real?

Each bounty opens with its whole reward locked in an on-chain escrow on Solana. Winners claim from that escrow to their own wallet once results post.

What does an entry actually consist of?

A public GitHub repository at one commit, plus the AI transcripts that built it. The server checks the code and grades it in a sandbox.

Does it cost anything to join?

Signing up is free. Some bounties have no entry fee at all; a few ask for a small one, and the bounty page always says so before you enter.
